Atlas Werkstatt

Leg ein neues Kit an oder öffne eines, das du schon hast. Die Werkstatt zeigt dir seine Abläufe, und du baust sie dort um.

>_Beim Öffnen geht zusätzlich ein Terminal-Fenster mit Claude auf. Lass es offen: Dort arbeitet die KI für dich und fragt dich, bevor sie etwas ändert, so wie es in Claude Code eingestellt ist.

Claude Code fehlt auf diesem Rechner. Die Werkstatt braucht es für die Arbeit der KI. Installier es von claude.com/claude-code und öffne Atlas Werkstatt danach noch einmal.
